FormVox is the fast, accessible, developer-friendly WordPress form builder plugin with drag & drop builder, 24+ field types, conditional logic, entries, and free Webhooks.

== Description ==

FormVox provides a modern, fast, and accessible drag-and-drop form building experience for WordPress site owners and developers. Unlike other plugins that hide essential features behind high per-site subscription paywalls, FormVox includes conditional logic, 24 field types, and arbitrary Webhooks in the core plugin for free.

= Key Features =
* **Fast Drag & Drop Builder**: Built with modern React and TypeScript in the admin area.
* **Server-Rendered Public Forms**: Zero React runtime overhead on the public site for maximum page load speed and SEO compatibility.
* **24 Core Field Types**: Single text, paragraph, name, email, phone, address, URL, number, slider, dropdown, radio, checkboxes, date/time, file upload, password, hidden, page break, section, HTML, star rating, Likert scale, NPS, layout columns, repeater.
* **Free Conditional Logic**: Show/hide fields, skip pages, and conditionally trigger email notifications.
* **Anti-Spam Suite**: Built-in honeypot + time-trap token, plus reCAPTCHA v2/v3, hCaptcha, and Cloudflare Turnstile integrations.
* **Integrations**: Stripe payments, Mailchimp opt-in, and free Webhooks.
* **20 Pre-Built Templates**: One-click form creation.
* **WPForms Importer**: Effortlessly import forms from WPForms Lite.

== Installation ==

1. Upload the `formvox` directory to `/wp-content/plugins/`.
2. Activate FormVox through the 'Plugins' menu in WordPress.
3. Navigate to **FormVox > Add New Form** to create your first form.

== Frequently Asked Questions ==

= Is conditional logic free? =
Yes! Conditional logic is included in FormVox Core at zero additional cost.

= Are entries stored as custom database tables? =
Yes. Entries are stored in custom database tables `{prefix}formvox_entries` for fast querying and scaling.
