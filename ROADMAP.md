# FormVox Product Roadmap

This document outlines the feature expansion phases planned for FormVox Pro and future core releases.

## Phase 2 (Pro Release)
- **Surveys & Polls UI**: Advanced reporting visualizer (charts, bar graphs, export reports).
- **Conversational Forms**: One-question-at-a-time interactive form flow.
- **Form Landing Pages**: Standalone dedicated URL landing pages for forms.
- **Digital Signatures**: Touch and mouse signature input field with image generation.
- **Calculations Engine**: Dynamic math and price formula calculator.
- **Coupons & Discounts**: Promo code input with percentage or fixed discount application.
- **User Registration**: Create WordPress user accounts automatically on form submission.
- **Post Submissions**: Allow visitors to submit blog posts or custom post types from the front end.

## Phase 3 (Advanced Integrations & Features)
- **Geolocation**: Auto-complete addresses and capture visitor country/city.
- **Save & Resume**: Allow users to save partial form entries and resume later via unique link.
- **Form Abandonment**: Capture partial entry data from un-submitted forms.
- **Offline Forms**: Service worker-based offline form submission sync.
- **PayPal & Square**: Expanded payment gateway support.
- **CRM & Marketing Addons**: Salesforce, HubSpot, ActiveCampaign, ConvertKit, MailerLite.
- **AI Form Generation**: Instant form schema generation using Gemini AI logic.
